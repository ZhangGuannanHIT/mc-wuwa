# 鸣潮 · Minecraft

MC × MC（bushi）

把专武放进队伍栏，就能在 Minecraft 里操作对应的共鸣者。1.0.0 版本收录 32 位角色，可以三人编队，在探索、采集和战斗之间随时切换。

## 角色配置

1. 击败能掉落声核的生物。拾取声核后，在工作台配方书里合成角色专武。
2. 打开背包，把专武放入右侧队伍栏。三个位置各对应一名角色，各自保留状态。
3. 选中快捷栏对应格子切换角色，切回其他快捷栏格即可使用工具或放置方块。

## 声骸与养成

击败能掉落声骸的生物，会获得该生物的声骸，其中BOSS生物（包括引入的鸣潮生物、原版BOSS生物、铁傀儡）为COST 4 ，敌对生物为COST 3，友好生物为COST 1。

声骸词条随机，数值为对应词条最大值。

打开角色配置页，按属性、COST 和套装搭配。角色页还可以查看面板、提升共鸣链和精炼专武。

## 科考摩托

按下面的配方合成摩托。用 **WASD** 驾驶，**J** 切换加速，潜行下车，潜行时右键空车可收回。带上琳奈可以提高动能上限。

| 左     | 中   | 右     |
| ------ | ---- | ------ |
| 铁锭   | 红石 | 铁锭   |
| 铁锭   | 声核 | 铁锭   |
| 黑曜石 | 空   | 黑曜石 |
